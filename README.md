# ShoppyGlobe E-Commerce Application

ShoppyGlobe is a basic e-commerce application developed using React and Vite.

## GitHub Repository

https://github.com/Sujaltonge384/ShoppyGlobe-E-commerce-Application

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- React Router
- JavaScript
- CSS
- DummyJSON API

## Features

- Product listing
- Product details
- Search products
- Add products to cart
- Remove products from cart
- Increase cart quantity
- Decrease cart quantity
- Cart quantity cannot go below 1
- Checkout form
- Order summary
- Place order functionality
- 404 Not Found page
- API error handling
- Lazy loading
- Responsive design

## API

Products are fetched from:

https://dummyjson.com/products

Product details are fetched dynamically using:

https://dummyjson.com/products/{id}

## Installation

Clone the repository:

git clone https://github.com/Sujaltonge384/ShoppyGlobe-E-commerce-Application.git

Move into the project:

cd shoppyglobe

Install dependencies:

npm install

Start the development server:

npm run dev

## Production Build

npm run build
